# images/

Imágenes de resultado de los prompts de AI Astrolab (campo `"image"` de `prompts.json`).

- Nombre de archivo = id del prompt (`p-YYYYMMDD-N.jpg|png|webp`).
- URL pública: `https://raw.githubusercontent.com/dariuss13-cyber/ai-astrolab-feed/main/images/<archivo>`
- Solo imágenes generadas por nosotros o con derechos de uso. Nunca copiadas de posts de terceros.
- Las sube la tarea diaria desde `AIAtlas\feed\images\` (ver LEEME.txt de esa carpeta).
